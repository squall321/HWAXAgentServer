# 보고있었니

> **이 저장소에 이 곡의 파일은 없다.** 사용자의 컴퓨터에 있다.

## 작업 위치

Remote Control 로 사용자 컴퓨터에 붙어서 작업한다.

1. `list_computer_folders` 로 공유 폴더 확인
2. 이 곡의 폴더를 `request_computer_folder` 로 연결
3. 목록이 비어 있으면 Remote Control 이 꺼진 것이다 — 그 컴퓨터에서
   Claude 데스크톱 앱 → 설정 → Claude Code → Remote Control 을 켜 달라고 요청한다

전용 세션: **「🎵 보고있었니 — 믹스·마스터링 (내 컴퓨터)」**

## 알려진 것

| | |
|---|---|

| | 「음악 프로젝트 진행상황 파악」 (보관됨, bridge 환경) |
| 추정 | 파일명에 `TLP_MixDown.wav` 가 있고 "음량 조정"이 제목이니 **믹스다운 이후 마스터링 단계**였을 가능성 |
| 산출 형식 | WAV / FLAC 을 쓰던 것으로 보인다(한 프로젝트가 14GB 였고 그중 9.7GB 가 WAV 였다는 기록) |

## 이 곡이 남긴 방법론

「곡을 짓는 법」 문서가 이 프로젝트에서 나왔고, 〈Moongate〉가 그걸 참고해 만들어졌다.
그 문서에 적혀 있던 것 중 실제로 반복해서 들어맞은 것:

- **자기 도구로만 검증하지 않는다.** 쓴 쪽과 읽는 쪽이 같은 코드면 뭘 세어도 맞는다.
  제3자(신시사이저)에게 먹여 보고서야 372초짜리가 512샘플로 돌아온 걸 알았다
- **두 번째 수정이 예상만큼 안 먹히면 멈춘다.** "덜 세게 고쳤나"가 아니라 "가설이 틀렸다"를 먼저 의심한다
- **납품 규격은 음악을 다시 쓸 이유가 아니다.** 마스터링에서 풀 문제를 작곡에서 풀려 하지 않는다
- **지표는 분모를 함께 출력한다**
