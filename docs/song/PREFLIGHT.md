# 사전 점검 프로토콜 — 다음 곡을 시작하기 전에

이번 곡("Moongate")에서 실제로 **되돌아갔던 지점**만 모아 만든 문서다. 일반론이 아니다.

되돌아간 열 건을 늘어놓고 보니 공통점이 하나였다 —
**N단계에서 내린 결정이 N-1단계에서 이미 쓴 것을 무효로 만들었다.**
음역·음절 수·최고음처럼 "나중에 정해도 되는 것"처럼 보이는 값들이, 사실은 첫 음을 쓰는 순간
이미 고정되어 버리는 값이었다. 그래서 이 문서의 절반은 **먼저 못 박을 값의 목록**이고,
나머지 절반은 **아직 아무도 이 곡을 듣지 못했다는 사실**에서 출발하는 잔여 작업 목록이다.

## 2. 첫 음을 쓰기 전에 못 박을 것 (Spec Lock)

다음 곡은 이 아홉 칸을 채우고 나서 작곡을 시작한다. 채우는 데 20분, 안 채우면 하루를 되돌린다.

| # | 항목 | 이번 곡의 값 | 이게 늦으면 무너지는 것 |
|---|---|---|---|
| ① | **재생 환경** | 카페·편집숍 / 천장 스피커 / 대화 소음 60–70dB / **사실상 모노** | 편곡 밀도, 훅 대역, 마스터 라우드니스, 스테레오 설계 전부 |
| ② | **악기별 음역 맵** | 베이스 A1–C4, 로즈 E2–E6, 기타 E3–C6 … | 믹스에서 사라지거나 뭉치는 파트 |
| ③ | **보컬: 전조 후 최고음부터 역산** | 전조 후 E5 상한 → 전조 전 D5 | 멜로디 전체. 나중에 고치면 코러스를 다시 쓴다 |
| ④ | **실제 악기의 물리 음역** | 로우 D 휘슬 D4–D6 (틴휘슬은 D5부터) | 연주 불가능한 악보 |
| ⑤ | **음절 그리드** | 벌스 6/6/7/7/6/7/7/7, 코러스 5/5/8/6/6/6/7/5 | 2절·3절 전면 재작성 |
| ⑥ | **고유명사·세계관 노출 수위** | 0개. 이미지로만 | 가사 전체 |
| ⑦ | **모니터링 경로** | ⚠ 이번엔 확보 못 함 (아래 §3 참조) | 모든 음악적 판단 |
| ⑧ | **길이와 섹션 마디 수** | 76마디 / 2:42 | 구조. 가사를 쓴 뒤 자르면 가장 아프다 |
| ⑨ | **"하지 않을 것" 목록** | 지르지 않는다 / 완전 무음 없다 / 고유명사 없다 / 40Hz 이하 없다 | 후속 결정마다 매번 다시 논쟁하게 된다 |

⑨가 실제로 제일 값싸고 효과가 컸다. "지르지 않는다"를 규칙으로 적어두면
"포스트코러스를 3도 위로 갈라자"는 아이디어가 **구현 전에** 걸러진다.

## 3. 아직 안 한 것 — 잔여 작업

### 0단계. 듣기 (나머지 전부의 전제)

> **지금까지의 검증은 전부 파싱이지 청취가 아니다.**
> 음정·음역·충돌·길이는 기계로 확인했지만, 이 곡이 **좋은지는 아무도 모른다.**
> 이 환경에는 fluidsynth·ffmpeg·DAW가 없어 소리를 낼 수 없었다.

- [ ] 로컬에서 `03_full.mid` 를 DAW 또는 사운드폰트로 렌더해 통청취
- [ ] 이 시점에서 구조·템포·조성이 뒤집힐 수 있다. 아래 작업은 그 다음이다

### 1단계. MIDI를 사람이 연주한 것처럼

현재 MIDI는 **완전 퀀타이즈 + 계단식 고정 벨로시티**다. 그대로 렌더하면 데모가 아니라 시퀀스로 들린다.

- [ ] 16비트 스윙 55~57% (기타 커팅·하이햇)
- [ ] 벨로시티 곡선 — 지금은 파트별 고정값 몇 개뿐
- [ ] 타이밍 오프셋: 베이스 살짝 앞, 보컬 살짝 뒤, 스네어 뒤로 눕히기
- [ ] 노트 길이 변주 (기타 커팅 1,056개가 전부 동일 길이)
- [ ] CC 데이터 전무 — 로즈 서스테인(CC64), 휘슬 비브라토(CC1)·익스프레션(CC11), 베이스 슬라이드(피치벤드)
- [ ] **휘슬 장식음(cut / strike / roll)** — 켈틱 휘슬은 장식음 없이는 가짜로 들린다. 이 곡의 정체성이 걸린 항목
- [ ] 드럼 고스트 노트, 하이햇 오픈/클로즈 변주, 필 실제 작곡 (현재는 톰 2방 자리표시)

### 2단계. 편곡 구멍

- [ ] **2절이 1절과 편성이 같다** — 카운터 멜로디나 대선율이 없으면 1:00–1:25가 지루해진다
- [ ] 섹션 이음새: 코러스 직전 1마디 드롭아웃, 라이저, 리버스 심벌(현재 브릿지 1회만)
- [ ] 이어캔디: 바이닐 노이즈 베드, 인트로 모닥불·빗소리(기획서 §5에 있으나 미구현)
- [ ] 아웃트로를 페이드로 끝낼지 루프 가능하게 마감할지 결정 (매장 재생 = 루프 유리)

### 3단계. 보컬 프로덕션

- [ ] 가수 섭외 후 **E5가 실제로 편한지** 재확인 → 아니면 전체 키 조정 (⑨ "지르지 않는다"가 기준)
- [ ] 컴핑 / 피치·타이밍 보정 **정도** 결정 — 과하면 세련미가 먼저 죽는다
- [ ] **스택 자음 정렬** — 리드·아래·위 3성부의 자음이 어긋나면 하모니가 뭉갠다. 하모니를 넣은 이상 필수
- [ ] 브레스 편집, 디에싱(천장 트위터에서 치찰음이 가장 먼저 피로를 만든다), 애드립
- [ ] 높은 음의 모음 점검 — 클라이맥스 "mor"는 개모음이라 통과. 닫힌 모음이 고음에 걸린 자리 재확인

### 4단계. 믹스

- [ ] 정적 밸런스 → 버스 구조 → 그 다음에야 플러그인
- [ ] 200–400Hz 정리, 40Hz 이하 하이패스 (기획서 §7)
- [ ] **모노 호환성** — 카페 천장 스피커는 사실상 모노다. 와이드너·코러스가 모노에서 사라지는지 반드시 확인. ①에서 파생되는 가장 중요한 제약
- [ ] 위상 점검(보컬 더블, 기타 2겹)
- [ ] 레퍼런스 A/B

### 5단계. 마스터링

- [ ] -9 ~ -8 LUFS(integrated), 트루피크 -1.0dBTP
- [ ] 재생 점검: 폰 스피커 / 노트북 / 이어폰 / **실제 카페 볼륨(대화 소음 위)**

### 6단계. 파생 버전

- [ ] **인스트루멘털** (주간 매장 재생용) — 기획서 §7에 이미 요구사항으로 있음
- [ ] **TV 사이즈 1:30** — 애니송 공식을 따랐으면 이건 당연히 필요하다
- [ ] 루프 가능 버전 / 스템 / 아카펠라

### 7단계. 메타데이터 · 권리

- [ ] 크레딧, BPM·키 태그, 커버아트, 가사 싱크(LRC)
- [ ] 지분 정리
- [ ] **제목 중복 검색** — "Moongate" 동명곡 확인
- [ ] 마비노기 이미지 차용은 가사·멜로디 직접 인용이 없어 문제없음 (§확정). 단 **커버아트에 게임 애셋 사용 금지**
- [ ] 생성형 툴을 쓴다면 해당 서비스 약관의 상업 이용 조건

### 8단계. 검수

- [ ] 일주일 귀를 쉬고 재청취
- [ ] 실제 매장에서 틀어보기
- [ ] 기획서 §8의 2문항 — *카페 테스트*(대화 중에 거슬리지 않는가) / *애니 테스트*(휘슬 모티프를 흥얼거릴 수 있는가)

## 4. 자동 검사 (`check.py`)

`python3 check.py` — 빌드 후 실행. 위 §1의 되돌아간 항목을 검사로 고정한 것이다.

| 검사 | 막는 사고 |
|---|---|
| [1] MIDI 구조·미결 노트 | 파일이 깨지거나 노트가 물려 있는 것 |
| [2] 음역 — 편곡 스펙 **및 실제 악기 물리 음역** | 베이스 D1 사고, 틴휘슬 사고 |
| [3] 섹션 타임코드·전체 길이 | 구조가 목표 길이를 벗어나는 것 |
| [4] 하모니 음정(3~5반음)·성부 교차 | 하모니가 2도로 부딪히거나 성부가 꼬이는 것 |
| [5] 하모니 vs 보이싱 반음 충돌 (**승인 목록** 포함) | 진짜 충돌은 잡고, 화성 언어인 rub 은 건드리지 않기 |
| [6] 가사 음절 그리드 1절 대 2절 | 2절 재작성 |
| [7] 전조를 반영한 실제 최고음 | 최고음 드리프트 |

**앞으로 추가할 검사**

- 음역 필터가 노트를 뺄 때 **조용히 빼지 말고 보고**하기 (§1의 6번)
- 리드 멜로디의 회피음 스캔 (지금은 하모니만 본다)
- 섹션별 노트 밀도 리포트 — "2절이 1절과 같다"를 수치로 잡기
- 퀀타이즈율·벨로시티 분산 리포트 — 휴머나이즈가 실제로 들어갔는지
