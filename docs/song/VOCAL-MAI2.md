# 보컬: Synthesizer V — Mai 2

"보고있었니"와 같은 보컬을 쓴다는 전제로 정리한 프로덕션 문서.

## 확인된 것 / 확인되지 않은 것

| | |
|---|---|
| 음원 | **Mai 2** — Dreamtonics, Synthesizer V Studio 2 용. 2025년 3월 SV2 에디터와 동시 배포 |
| 원 음원 | Mai (2022년 11월, AI 음성 DB). 보이스 프로바이더 키타 호노카 |
| 성격 | J-Pop·댄스·아이돌 지향의 또렷한 팝 보컬. **고음역 팔세토가 자연스럽다** |
| 언어 | Dreamtonics 크로스링구얼 — 일본어 음원이지만 **영어·중국어를 노래할 수 있다** |
| 보컬 모드 | Mai 2 는 전면 재수록으로 6종: Breathy / Downer / Emotional / Powerful / Rap / Sweet |
| **권장 음역** | **공개되지 않음.** AI 전용 음성 DB 는 음역·템포 프로필을 공개하지 않는다 |

> 마지막 줄이 이 곡의 키 결정 방식을 바꾼다. **"음역표를 보고 키를 정한다"가 이 보컬엔 성립하지 않는다.**
> 대신 렌더가 사실상 공짜이므로 **테스트로 정한다**. 현재 D major(리드 D4–E5)를 기본값으로 두고,
> 후보 조를 실제로 렌더해 비교한 뒤 `TRANSPOSE` 를 고친다.
> 후보 목록은 `python3 check.py --fit <최저음> <최고음>` 이 뽑아준다.
> "고음역 팔세토가 자연스럽다"는 성격상 **E5 는 오히려 강점일 가능성이 높다**.

## 임포트

`03_full.mid` 의 보컬 3트랙은 **전 노트에 가사 이벤트(FF 05)가 붙어 있다** (린터 [8]이 검사).
371 + 112 + 46 개 음절을 손으로 입력할 필요가 없다. 2절은 1절과 다른 가사가 들어가 있다.

- 트랙 언어를 **English** 로 설정
- 나머지 7개 악기 트랙은 뮤트하거나 DAW 로 따로 라우팅

> ⚠ SynthV 의 MIDI 가사 임포트 동작은 이 환경에서 검증하지 못했다. 읽지 못하면
> 가사 입력창에 한 행씩 붙여넣어 선택 노트에 분배하는 방식으로 대체한다(가사는 §악보에 행 단위로 있다).

## 영어 발음 — 손봐야 할 자리

일본어 기반 음원의 크로스링구얼 영어다. 자동 음소 변환이 무너지는 자리만 추린다.

**① 긴 음 위의 이중모음** — 활음(glide)을 음 끝으로 밀지 않으면 두 음절로 들린다. 최우선.

| 가사 | 위치 | 문제 |
|---|---|---|
| `home` /hoʊm/ | 포스트코러스 태그, **2박** | "호-우움" 으로 갈라진다 |
| `loud` /laʊd/ | 브릿지 4마디, **2박** | 위와 동일 |
| `now` /naʊ/ | 브릿지 2마디, **2박** | 위와 동일 |
| `mor`(-ning) /mɔːr/ | **클라이맥스 롱톤 2박** | r 색채를 늦게 넣지 않으면 으르렁대는 소리가 난다 |

**② 자음 뭉침** — 어말+어두 충돌.

- `The **world** can` (V2 5마디) — /rld/. 이 곡에서 가장 어려운 단어다.
  음소 수동 편집으로 안 되면 가사를 바꾼다(예: `The whole thing ends Sunday`).
- `mar-ket clos-ing` (t+k) · `keeps the cold out` (ps+ð, ld+aʊ) · `spend it slow-er` (nd+sl) ·
  `last life` (st+l) · `thou-sand times` (nd+t) · `stand-ing here` (ŋ+h)

**③ 일본어에 없는 음소** — 후크 단어에 걸린 것만.

- `fea-ther` /ð/ + r — **코러스 훅 단어**. 여기가 뭉개지면 훅이 죽는다
- `give` /v/ — 강박 위 (`Give me one white feather`)
- `thou-sand` /θ/ — 코러스 3마디
- 다크 L: `gold` `told` `still` `fall` `all` `floor`

**④ `moongate`** — 두 노트로 나뉘어 있지만 한 단어다. 자동 음소가 사이에 성문 폐쇄를 넣으면
두 단어로 들린다. `m uw n` / `g ey t` 로 이어 붙는지 확인.

## 이 보컬을 쓰기 때문에 달라지는 것

- **스택 자음 정렬 문제가 사라진다.** 사람이 3번 겹녹음하면 자음이 어긋나 뭉개지지만,
  하모니 3트랙의 노트 타이밍과 음절이 동일하므로 합성은 자동으로 정렬된다.
  `PREFLIGHT.md` 4단계에서 이 항목을 내렸다.
- **보컬 트랙은 휴머나이즈하지 않는다.** 피치 드리프트·비브라토는 SynthV 가 생성한다.
  퀀타이즈 해제·벨로시티 곡선은 **악기 트랙에만** 적용한다.
- **키 변경 비용이 거의 0** 이다. 사람이면 다시 불러야 하지만 여기선 `TRANSPOSE` 하나다.
- 컴핑·피치보정·브레스 편집이 빠지고, 대신 **파라미터 작업**(Tension, Breathiness, Loudness,
  Vocal Mode 자동화)이 들어온다. "지르지 않는다"는 Powerful 회피 + Tension 낮춤으로 구현된다.
