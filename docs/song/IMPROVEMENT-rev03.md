# rev03 개선안 — 계측이 가리킨 곳만 고친다

`quality.py` 를 새로 만들어 지금까지 안 재던 축을 쟀다. 감이 아니라 이 숫자에서 시작한다.

## 계측 결과와 그 해석

| 축 | 측정값 | 해석 |
|---|---|---|
| 드럼 마디 자기유사도 | **92.2%** (인트로 100%) | 스타일당 모든 마디가 복붙. 베이스는 1.8%인데 드럼만 이 상태 |
| 기타 / 로즈 자기유사도 | 34.6% / 33.6% | 나쁘지 않다. 손대지 않는다 |
| 섹션 진입 장치 | 11곳 중 10곳이 **동일**(톰 필+크래시) | 모든 전환이 같은 소리로 준비된다. 4→5마디(첫 보컬)는 준비가 아예 없음 |
| 대역 점유 | 중고역+고역이 **70~90%** | 상단 편중. 중역(D3~D4) 0~13%, 저역(<D2) 전 구간 0% |

## 고칠 것 네 가지

### P1. 드럼 — 92% → 70% 이하

지금은 `verse`/`four` 스타일 하나가 그 섹션 전 마디에 그대로 복사된다. 실제 드러머는
2마디·4마디 단위로 호흡한다.

- **고스트 노트** — 백비트 사이 16분에 아주 약한 스네어. 그루브의 "포켓"은 여기서 나온다
- **하이햇 강약 패턴** — 2마디 단위로 악센트 위치를 돌린다. 오픈 하이햇은 매 업비트가
  아니라 **구절 끝에만** (지금은 마디당 4번 = 과다)
- **4마디 프레이즈 인식** — 프레이즈의 4번째 마디는 다른 패턴을 쓴다
- **필을 실제로 작곡** — 지금은 톰 2방 자리표시. 위치별로 다른 필을 쓴다

### P2. 중역(D3~D4)을 채운다

로즈가 지금 오른손 보이싱만 친다. 실제 로즈 연주자는 **왼손이 낮은 자리**를 잡는다.
로즈에 D3~D4 왼손 성부를 추가한다 — 새 트랙 없이 있는 악기의 연주 방식을 고치는 것.

### P3. 저역에 실제 무게

베이스가 D2(73Hz) 아래로 안 내려간다. 현대 팝 베이스의 기음은 보통 E1~A1(41~55Hz)이다.
**기획서의 "40Hz 이하 없다" 규칙은 E1(41.2Hz)을 금지하지 않는다** — 지금이 과하게
보수적이었다. 코러스 강박에서 옥타브 아래로 내려가되 **E1(28) 을 하한으로 고정**한다.

### P4. 전환을 다르게

11곳을 세 종류로 나눈다 — 필로 미는 곳 / 비워서 떨어뜨리는 곳(드롭) / 역방향 심벌로
빨아들이는 곳. 그리고 **4→5마디(첫 보컬 진입)에 준비를 만든다**.

### P5. 렌더 음질 (인지 품질)

사용자가 이 MP3 로 판단한다. 편곡이 좋아도 합성이 싸구려면 싸구려로 들린다.
드럼 트랜지언트 보강, 버스 글루 압축, 스테레오 폭 — 편곡 판단을 오염시키지 않을 만큼만.

## 하지 않을 것

- 기타·로즈 리듬 패턴 (자기유사도 34%, 이미 충분)
- 멜로디·가사 (rev01~02에서 계측 후 고쳤고 새 근거 없음)
- 새 악기 트랙 추가 (있는 악기의 연주 방식으로 먼저 푼다)
