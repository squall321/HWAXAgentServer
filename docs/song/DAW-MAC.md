# 맥북 DAW 로 굽기 — Logic Pro / GarageBand

**결론부터: 된다. 그리고 여기서 굽는 것보다 낫다.**
이 저장소의 `render_sf.py` 는 FluidR3 라는 **GM 범용 사운드폰트**를 쓴다. 2008년 무료 음원이고
"모든 악기를 한 벌에" 담은 물건이라 악기 하나하나의 질은 Logic 기본 악기에 못 미친다.
Logic 의 Vintage Electric Piano 나 Drum Kit Designer 는 그 악기 하나만을 위해 만들어진 음원이다.

## 곡 정보 (DAW 프로젝트 설정)

| | |
|---|---|
| 템포 | **112 BPM** (곡 전체 고정, 변속 없음) |
| 박자 | **4/4** |
| 조 | **D major** — 61마디부터 **E major** 로 전조(+2반음) |
| 길이 | **76마디 / 2분 42초** |
| MIDI 해상도 | 480 PPQ |

MIDI 파일에 템포·박자·조표 메타이벤트가 들어 있어 임포트하면 자동으로 잡힌다.

## 무엇을 가져가나

`stems_rev06/` 안에 **트랙당 파일 하나씩** 들어 있다. 합본(`03_full_rev06.mid`)을 통째로
넣지 말고 이쪽을 쓴다 — 합본을 임포트하면 DAW 가 채널을 제 방식대로 배치해서 악기 배정을
다시 하게 되는 경우가 많다.

```
stems_rev06/
  01_Lead_Vocal_guide.mid          <- Synthesizer V (Mai 2) 로. DAW 아님
  02_Vocal_Harmony_3rd_below.mid   <- 위와 같음
  03_Vocal_Harmony_3rd_above.mid   <- 위와 같음
  04_Signature_Whistle.mid
  05_Rhodes.mid
  06_Guitar_16th_chops.mid
  07_Bass.mid
  08_Celtic_Harp.mid
  09_Strings.mid
  10_Drums.mid                     <- 킥·스네어·림·탐·크래시
  11_Percussion.mid                <- 하이햇·셰이커·탬버린·라이드 (별도 트랙!)
```

**보컬 3트랙은 DAW 가 아니라 SynthV 로 간다.** 전 노트에 가사 이벤트가 붙어 있고,
DAW 로 열면 그 가사가 버려진다. 자세한 건 `VOCAL-MAI2.md`.

## 악기 배정

> ⚠ 아래 음원 이름은 Logic 버전과 설치한 사운드 라이브러리에 따라 다르게 보일 수 있다.
> **이 환경엔 macOS 도 Logic 도 없어서 실제 패치 경로를 확인하지 못했다.** 카테고리와
> "무엇을 찾으면 되는지"를 적는다.

| 스템 | 음역 | Logic Pro | GarageBand | 찾는 요령 |
|---|---|---|---|---|
| **Rhodes** | D3–F#4 | **Vintage Electric Piano** | Electric Piano | 곡의 화성 몸통. Suitcase 계열의 부드러운 프리셋. 트레몰로는 얕게 |
| **Bass** | E1–B3 | **Studio Bass** 계열 핑거 베이스 | Electric Bass | 픽이 아니라 **핑거**. E1(41Hz)까지 내려가니 서브가 나오는 음원이어야 한다 |
| **Drums** | GM 드럼맵 | **Drum Kit Designer** | Drum Kit | ★아래 "드럼맵" 주의 |
| **Percussion** | GM 드럼맵 | 같은 드럼 음원 또는 퍼커션 | 같음 | **킷과 따로 둔 이유가 있다** — 아래 참고 |
| **Guitar (16th chops)** | E3–B5 | 클린 일렉 (Strat 계열) | Clean Electric | 16분 커팅이라 **어택이 빠르고 감쇠가 짧은** 프리셋. 리버브 적게 |
| **Signature Whistle** | F#4–F#5 | 우드윈드의 **Flute / Irish Whistle** | Flute | 이 곡의 시그니처 선율. 틴휘슬이 있으면 최선, 없으면 플루트 |
| **Celtic Harp** | F#4–F#6 | **Orchestral Harp** | Harp | 아르페지오 전용 |
| **Strings** | F#4–E6 | **Studio Strings** 소편성 | Strings | 대편성 아님. 어택 느린 앙상블 |

### ★ 드럼과 퍼커션을 왜 갈라 놨나

한 트랙이면 **믹스에서 킥과 하이햇의 비율을 만질 수 없다.** 실제 렌더 스펙트럼을 재 보니
드럼 에너지의 **78%가 250Hz 아래**였고(킥이 다 먹었다) 8~16kHz 는 **0.6%** 였다.
갈라 놓고 퍼커션만 올리자 에어 대역이 **10~14dB** 올라왔다. DAW 에서도 두 트랙으로 두고
**퍼커션 쪽 페이더를 따로 잡는 걸 권한다.**

### ★ 드럼맵 주의

드럼 스템은 **GM 드럼맵**으로 쓰여 있다. Logic 의 Drum Kit Designer 는 대체로 GM 과
호환되지만, 이 곡은 아래 소리를 쓰니 임포트 후 **한 번은 들어보고 확인**해야 한다.

| 노트 | 소리 | 이 곡에서의 역할 |
|---|---|---|
| 36 | 킥 | |
| 37 | 림쇼트 | **벌스의 뼈대** — 스네어 대신 림을 친다. 이게 스네어로 바뀌면 벌스가 시끄러워진다 |
| 38 | 스네어 | 고스트 노트가 vel 26~30 으로 들어 있다. **약한 벨로시티가 살아나는 음원**이어야 포켓이 산다 |
| 42 / 46 | 클로즈드 / 오픈 하이햇 | 오픈햇은 2마디 구절 끝에만 |
| 45 / 47 | 로우탐 / 미드탐 | 필 전용 |
| 49 | 크래시 | 섹션 진입 |
| 51 | 라이드 | 65~72마디. 마지막 코러스~아웃트로의 광채 |
| 54 | 탬버린 | 코러스·포스트의 8분 업비트. 고역 담당 |
| **82** | **셰이커** | 드럼이 빠지는 구간을 혼자 채운다. ★rev06 까지 **70(마라카스)** 을 셰이커로 잘못 쓰고 있었다 — GM 셰이커는 **82** 다 |

## 순서

1. 새 프로젝트 → **112 BPM, 4/4**
2. `stems_rev06/` 의 **04~10** 을 각각 새 트랙으로 드래그 (보컬 01~03 은 제외)
3. 트랙마다 위 표대로 악기 배정
4. 보컬 3개는 **Synthesizer V** 로 따로. 트랙 언어 **English**, 섹션별 보컬 모드는
   `VOCAL-MAI2.md` 표대로 (Powerful 은 쓰지 않는다)
5. SynthV 출력을 오디오로 뽑아 DAW 로 되가져와 반주 위에 얹는다

## 믹스 참고값

`render_sf.py` 가 쓰는 값이다. Logic 음원은 레벨이 다르니 **그대로 넣지 말고 출발점으로만** 쓴다.
비율이 요점이다 — 드럼·베이스가 바닥을 잡고, 로즈가 화성의 몸통, 기타는 그 사이를 긁고,
휘슬은 선율이라 앞에 나오되 리버브로 멀리 둔다.

| 트랙 | 상대 레벨 | 팬 | 리버브 센드 |
|---|---|---|---|
| Drums | 1.00 (기준) | C | 0.07 |
| Bass | 0.80 | **C (모노·드라이)** | 0.02 |
| Rhodes | 0.53 | L 16 | 0.17 |
| Signature Whistle | 0.48 | R 8 | 0.26 |
| Guitar | 0.35 | **R 26** | 0.11 |
| Celtic Harp | 0.33 | **L 28** | 0.26 |
| Strings | 0.29 | C (와이드) | 0.30 |

- **베이스는 모노로, 리버브 거의 없이.** 카페 천장 스피커에서 저역이 뭉치지 않게 하는 전제다
- 로즈(L)와 기타(R)를 반대편에 앉힌다 — 둘 다 중역에서 코드를 치므로 갈라 놔야 한다
- 목표 라우드니스 **-17dBFS RMS 근처.** 배경음악이라 브릭월까지 밀지 않는다
- 섹션 다이내믹은 인트로 → 포스트코러스가 약 **5dB** 차이. 이 곡선이 편곡 의도다
